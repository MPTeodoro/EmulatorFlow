Como funciona

01

Conecta no emulador

BlueStacks, LDPlayer, MEmu, NoxPlayer ou celular físico. O app detecta via ADB automaticamente.

02

Tira print das telas

Screenshot direto do emulador, salvo na galeria do projeto. Usa como referência para o nó de esperar imagem.

03

Arrasta os blocos

Clique, swipe, digitar texto, esperar imagem aparecer, lógica de loop — cada ação é um nó que você conecta.

04

Roda e acompanha

O fluxo executa nó a nó em tempo real. Você vê exatamente em qual passo o bot está.

Galeria por projeto

Cada projeto tem sua própria pasta de imagens. Sem misturar prints de jogos diferentes.

Roda múltiplos fluxos

Dá pra ter um bot rodando enquanto você edita ou testa outro. Cada execução fica independente.

Importa e exporta JSON

Salva o fluxo inteiro num arquivo, manda pra alguém, importa de volta. Compartilhamento simples.

IA gera o fluxo pra você

Descreve o que o bot tem que fazer com suas palavras. A IA monta os nós — você ajusta o que precisar.

Atualiza sozinho

Quando sair uma versão nova, o app avisa e instala em segundo plano. Sem ficar baixando manualmente.

Reconhecimento de imagem

Espera um elemento aparecer na tela antes de continuar. Funciona com qualquer jogo.

O EmulatorFlow é um projeto open source, feito por um desenvolvedor solo.
