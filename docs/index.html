Como começar

1

Baixe e instale o EmulatorFlow

Execute o instalador acima. Se aparecer aviso do Windows, clique em "Mais informações" → "Executar assim mesmo".

2

Abra seu emulador

BlueStacks, LDPlayer ou qualquer emulador Android. No EmulatorFlow, clique no ícone de scan para detectar automaticamente.

3

Tire um print e crie seu fluxo

Use o botão Screenshot para capturar telas do jogo. Arraste os nós para o canvas e conecte-os para definir o comportamento do bot.

4

Clique em Run

O bot executa no emulador em tempo real. Você pode acompanhar o fluxo sendo executado nó a nó.
